# Vouch Protocol - Chrome Web Store Listing

## Extension Name
**Vouch Protocol - Sign & Verify Text**

## Short Description (132 chars max)
Sign any text with cryptographic proof. Trust-On-First-Use identity verification for your posts, comments, and messages.

## Detailed Description

### 🔐 Prove Your Words Are Yours

Vouch Protocol lets you cryptographically sign any text on the web. Select text, right-click, and create a verifiable signature that proves:

✅ **You wrote it** - Ed25519 digital signature
✅ **It hasn't been modified** - Tamper-evident
✅ **Your identity** - Linked to your Google account

### 🎯 Perfect For

• **LinkedIn posts** - Sign your thought leadership
• **Dev.to articles** - Prove authorship
• **Hacker News comments** - Stand behind your opinions  
• **Blog posts** - Author authenticity
• **Any text on any website**

### 🛡️ How It Works

1. **Sign**: Select text → Right-click → "Sign with Vouch"
2. **Share**: Paste the signed block anywhere
3. **Verify**: Anyone with Vouch sees ✅ verified badges automatically

### 🔑 Trust-On-First-Use (TOFU)

Like SSH fingerprints, Vouch remembers who you've seen before:
• 🔵 New Identity - First time seeing this signer
• ✅ Verified Contact - Matches known contact
• ⚠️ Warning - Key changed (possible impersonation!)

### 🔒 Privacy-First

• Keys generated locally - never leave your device
• No account required
• No data collection
• Open source: github.com/vouch-protocol/vouch

### 💻 Technical Details

• Ed25519 elliptic curve cryptography
• Base64-encoded signatures (compact)
• Works on any website
• Lightweight (~50KB)
